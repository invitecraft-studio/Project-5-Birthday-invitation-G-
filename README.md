# Daanvi’s Princess Garden Birthday Invitation
Vite project (HTML + CSS + JavaScript). Tap the bow to open, tilting invite card, countdown, tap-to-open family cards, wish lantern sky, WhatsApp RSVP.

    npm install
    npm run dev                # local preview
    npm run build              # production build in dist/ (deploy to Vercel / Netlify)
    npm run build:standalone   # one double-clickable file: dist-standalone/index.html

Edit **src/data/party.js** to change name, age, date, time, venue, Andhra Pradesh address, parents, programme and the WhatsApp number (919876543210, country code, no +).
Replace pictures in **src/assets/** keeping the same file names.
Personal links: https://your-site/?guest=Fatima
Vercel: import the repo, framework Vite, build command `npm run build`, output `dist`.
